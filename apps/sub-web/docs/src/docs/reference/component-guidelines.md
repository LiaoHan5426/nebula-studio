# 组件使用规范

## 可访问性

页面只保留一个主标题；图标按钮必须有可感知名称。状态不能只依赖颜色，错误信息应与字段建立关联。

## 内容规范

按钮使用明确动词，危险操作说明对象、影响和恢复方式。专业缩写首次出现时提供中文解释。

## 键盘行为

焦点顺序与视觉顺序一致。对话框打开后聚焦首个有效控件，关闭后恢复到触发元素；列表和菜单支持方向键与 Escape。

## 响应式

320 px 下主要任务保持单列，不依赖横向滚动。表格只用于跨记录比较或批量操作，单对象内容进入详情页或抽屉。

## 常见组合

- 页面标题 + 筛选栏 + 结果摘要 + 空状态。
- 详情抽屉 + 关联实体跳转。
- 表单 + Schema 提示 + 变更预览 + 二次确认。
