# @nebula-studio/vsh

Workspace-level development CLI. ESLint/Oxlint own source-local rules; this package owns checks requiring package graphs, generated artifacts, or repository-wide state.

- `nebula-vsh scan-circular`
- `nebula-vsh check-workspace`
- `nebula-vsh check-boundaries`
- `nebula-vsh check-generated`
- `nebula-vsh check-inventory`
